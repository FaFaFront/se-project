One purple. One pill. Everything else stays quiet.

Tutorist is a tutor-marketplace app — students book paid sessions with tutors by subject. Every base component shares one action color (--primary) as its hover/focus/active signal, one shared 40px control height, and a deliberate radius split: buttons are the system's only pill, every form control sits at a quieter 8–10px corner. This page catalogs the real tokens and the six base components that ship today, reproduced from the live Tailwind classes.

Do's & don'ts

Do Keep --primary as the single hover/focus/active signal across every control — that consistency is what makes a mixed form read as one system.
Don't Introduce brand-plum as a second action color. Today it has exactly one usage — the nav wordmark.
Do Keep buttons as the one pill-shaped surface, and every form control at its existing 8px or 10px radius.
Don't Round a button down to match a form control, or round a form control up to a pill.
Do Reuse the shared 40px control height when adding a new form component, so it aligns on a row with Input/Select/Button.
Don't Hardcode copy at call sites — override the components' existing English defaults via props instead of duplicating strings.
Do Match the existing error contract (red border + inline message via an error/errorMessage prop pair) on any new form control.
Don't Invent a success/valid visual state ad hoc — --success is a reserved token with no defined component usage yet.

Known gaps

What the base component set doesn't cover yet.

Success state--success is a defined token but no component has a success/valid visual state — only error exists.
Focus ringForm controls change border color on focus but don't declare a separate focus-visible ring.
Brand-plum usageThe plum range has tokens and Tailwind classes wired up but only one real usage (the nav wordmark) — no documented rule for when to use it.
Dark modetailwind.config.ts sets darkMode: "class" but no base component branches on it yet.
Icon setIcons come ad hoc from lucide-react — no curated subset or naming convention.
Layout componentsNavbar.tsx / Footer.tsx consume these primitives but aren't themselves reusable base components — out of scope here.
