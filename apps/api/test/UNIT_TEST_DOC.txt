_________________________________________________________
All tests are unit tests. The database (Prisma), Redis, Google Cloud Storage
and the browser's localStorage/fetch are fakes, so nothing has to be running.
The route tests (RT) start the real Express app on a random local port.

A case with several inputs runs once per input, so the 337 test IDs below
produce 653 test runs. The 7 Redis tests in redis-publisher/redis-subscriber
are older and have no IDs. Search a test ID in the test files to see its code.
